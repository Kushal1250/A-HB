# Key-only sequences

All nine chapters begin locked on every page load, including with saved progress. Choose the named chapter key, then complete the interaction or use the accessible “Use this key to open” button. Both routes require key selection. Later chapters require the preceding chapter’s collected key.

Only one chapter body is mounted at a time. Chapter navigation or entering another chapter by scrolling closes the old body. Use its key again to revisit. Collected keys remain saved for prerequisites and the keyring. Quiet mode and reduced motion retain key gates. The open-all and direct-open controls have been removed. Content and uploaded files remain unchanged.

Run: extract the ZIP, open anu-birthday-mern, double-click START-LOCAL.cmd, and visit http://localhost:3000. Browser and Windows manual checks remain unverified in this environment.

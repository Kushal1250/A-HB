52 VIDEO MEMORIES — ANU'S BIRTHDAY

Extract the whole ZIP into a NEW folder (do not merge over your running project).
Open CMD in the extracted anu-birthday-mern folder.
If Node still reports version 22, run:
  set "PATH=C:\Program Files\nodejs;%PATH%"
Then run:
  npm run install:all
  npm start
Open http://localhost:3000

Use the Memory Key in chapter 06 to reveal the photos and 52 videos.
Tap a video's play control to watch it. Videos never autoplay; playing one
pauses background music and other clips. Music can be resumed with its control.
Every video has a short editable caption and a poster preview.

Edit at http://localhost:3000/admin using your existing account, in Video
memories. Edit captions/titles, reorder, hide, remove, or add clips; then save
and publish. Future MP4 uploads have a 15 MB limit. The supplied larger clip
has already been imported and works without reuploading.

Your supplied project data, photos and chapter music are included. Keep this
folder private: data contains personal media and local account records. Do not
commit data to a public repository. The server listens only on this computer.

## Easiest start on Windows

1. Extract the ZIP into a new folder, for example `C:\Users\patel\Downloads\anu-birthday-local-3000`.
2. Open the inner folder containing `package.json` and `START-LOCAL.cmd`.
3. Double-click **START-LOCAL.cmd**.
4. The launcher installs dependencies if missing, builds the frontend and starts the local server. The browser opens after startup.
5. Keep the command window open. Press Ctrl+C there to stop the app.

Use Node.js **24 LTS, version 24.15.0 or newer**. Node.js 22.17.0 is not supported by the project's development dependencies. The launcher checks the version and gives a readable message before installation.

## Start with CMD instead

Open CMD in the extracted project folder — the one containing `package.json`.

First time only:

```cmd
npm run install:all
```

Then start:

```cmd
npm start
```

Open **http://localhost:3000**.

The server serves React, the API, photo thumbnails, full photos and audio on that same address. It binds only to `127.0.0.1`, not your Wi-Fi/network interface. It will not switch to port 3001 if port 3000 is occupied; stop the other app and retry.

You do not need two terminals, `npm run seed`, `.env` files, a database server or a cloud account. The previous cloud deployment configuration has been removed from this local edition.

The app creates a `data` folder when it starts:

```text
data/
  birthday.json
  uploads/
```

This contains your saved messages, drafts, password hashes and media. Existing uploaded data is retained in this updated ZIP; new runtime data remains local and is ignored by Git. Do not delete `data` if you want to keep your changes. Stop the server, then back up the entire `data` folder before moving/reinstalling the app.

The initial default content is in `shared/defaults.json`. Changing that file affects new installations and the frontend's emergency fallback; it does not overwrite existing saved content. Use the studio to edit existing local data.

Photos support JPEG/PNG/WebP up to 8 MB. Images are resized, rotated and converted to WebP, and EXIF metadata is removed. Music supports MP3/WAV up to 15 MB. Upload processing and storage happen locally. Music starts only when clicked.

## If something does not work

- **Node version too old:** install a compatible Node.js 24 LTS version, close CMD and open a new one.
- **Port 3000 already in use:** stop your other local app. This app deliberately does not select another port.
- **Page will not load:** keep the `npm start` window open and wait for the `Open: http://localhost:3000` line.
- **Admin account missing:** stop the server, run `npm run admin:create`, then restart.
- **Saved changes not visible:** saving creates a draft. Publish the saved draft, then refresh the visitor page.
- **Uploads missing after moving folders:** copy the whole old `data` folder while the server is stopped.
- **Private draft photo link expired:** refresh the studio's files and reopen the saved preview.
- **Windows Defender or browser prompts:** the app is local-only and should not need public-network access.
